# MyPrime-CS · האפליקציה המלאה - מדריך הקמה

זו האפליקציה המלאה: העוזר החושב (Sonnet), קריאה וכתיבה לגיליון, שליחה לאישור, אישור של Ron, והתראות. יש חלק אחד של הקמה חד-פעמית מול גוגל, ואלווה אותך בו. קרא עד הסוף לפני שמתחילים.

## שני מסכים
- `/` - העוזר של טלי ואפי (הדבקת הודעה, תשובה או ניסוח).
- `/approve.html` - מסך האישורים של Ron.

## מה צריך להכין (חד-פעמי)

### 1. חשבון שירות של גוגל (בשביל הכתיבה לגיליון)
1. נכנסים ל-console.cloud.google.com, יוצרים פרויקט (או בוחרים קיים).
2. מפעילים את "Google Sheets API" (חיפוש בשורת החיפוש למעלה, Enable).
3. תפריט: IAM & Admin ← Service Accounts ← Create service account. נותנים שם, Create.
4. אחרי היצירה, נכנסים אליו ← Keys ← Add key ← Create new key ← JSON. יורד קובץ JSON. שומרים אותו.
5. פותחים את הקובץ, ומעתיקים את כתובת המייל שבשדה `client_email` (משהו כמו ...@...iam.gserviceaccount.com).

### 2. לשתף את הגיליון עם חשבון השירות
בגיליון, לוחצים "שתף", מדביקים את כתובת המייל של חשבון השירות, ונותנים לו הרשאת **עורך** (Editor). שומרים.

### 3. לשתף את הגיליון לקריאה
בנוסף, "כל מי שיש לו הקישור - צופה", כמו קודם.

### 4. להוסיף לשונית "התראות"
בגיליון, מוסיפים לשונית חדשה בשם **התראות**, ובשורה הראשונה כותבים את הכותרות:
`מתי` | `אל` | `סוג` | `טקסט` | `הפניה` | `נקרא`

## העלאה ל-Vercel
1. מחברים את התיקייה לגיט ולוורסל כרגיל.
2. בהגדרות הפרויקט בוורסל, Settings ← Environment Variables, מוסיפים שניים:
   - `ANTHROPIC_API_KEY` = מפתח ה-API של Anthropic.
   - `GOOGLE_SERVICE_ACCOUNT` = כל התוכן של קובץ ה-JSON מחשבון השירות (מדביקים את כל הקובץ).
3. Deploy.

## אחרי ההעלאה
- טלי ואפי נכנסות לכתובת הראשית.
- Ron נכנס ל-`/approve.html`.
- מזהה הגיליון כבר מוגדר ב-`lib/config.js`. אם תחליף גיליון, מעדכנים שם בלבד.

## הזרימה
1. טלי מדביקה הודעה. קודם ניסיון התאמה מדויקת, חינם. אם יש - מוגשת מיד.
2. אם אין, המנוע החושב (Sonnet) פועל: או שואל השלמות בכפתורים, או מנסח הצעה.
3. טלי עורכת ושולחת לאישור Ron. Ron מקבל התראה.
4. Ron מאשר או מחזיר. באישור, התשובה נכתבת לגיליון כ"מאושר", וטלי מקבלת התראה.
5. מאותו רגע, אותה שאלה תימצא בהתאמה מדויקת חינם.

## הערות
- המודל מוגדר ב-`lib/config.js` (כרגע Sonnet). ניתן לשנות שם.
- כל בלוק אחראי לדבר אחד: `lib/sheets` נתונים, `lib/ai` חשיבה, `lib/engine` התאמה, `lib/wrap` עטיפה, ותיקיית `api` נתיבי השרת.
