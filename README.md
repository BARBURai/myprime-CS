# MyPrime-CS · מדריך

כתובת אחת לכולם. כל אחד נכנס עם מייל וקוד אישי, והמסכים שהוא רואה נגזרים מהתפקיד שלו.

- מנהל: עוזר תשובות, אישורים, ניהול משתמשים.
- מנהלת שירות ונציג: עוזר תשובות בלבד.

## מה צריך בגיליון (חד-פעמי)

### לשונית "התראות"
כותרות בשורה הראשונה: מתי | אל | סוג | טקסט | הפניה | נקרא

### לשונית "משתמשים"
כותרות בשורה הראשונה: שם | מייל | קוד | תפקיד | פעיל

ואז מוסיפים ידנית שורה אחת בלבד, שלך, כדי שתוכל להיכנס בפעם הראשונה:
- שם: רון
- מייל: המייל שלך
- קוד: קוד שתבחר
- תפקיד: מנהל
- פעיל: כן

מרגע שנכנסת, את כל שאר המשתמשים מוסיפים מתוך האפליקציה, בלשונית משתמשים.

### שיתוף
- הגיליון משותף עם חשבון השירות בהרשאת עורך.
- שירות Google Sheets API מופעל בפרויקט בגוגל קלאוד.

## משתני סביבה ב-Vercel
- `ANTHROPIC_API_KEY` — מפתח Anthropic.
- `GOOGLE_SERVICE_ACCOUNT` — כל תוכן קובץ ה-JSON של חשבון השירות.
- `VAPID_PUBLIC_KEY` — מפתח הפוש הציבורי.
- `VAPID_PRIVATE_KEY` — מפתח הפוש הפרטי.

## התראות פוש
כדי שהתראות יגיעו לטלפון גם כשהאפליקציה סגורה:
1. להוסיף בגיליון לשונית בשם **מנויים**, עם הכותרות: אל | endpoint | p256dh | auth | מתי
2. להוסיף ב-Vercel את שני מפתחות ה-VAPID.
3. בכניסה ראשונה מכל מכשיר, לאשר את בקשת ההתראות שקופצת.
4. בטלפון, להוסיף את האתר למסך הבית. באייפון זה תנאי הכרחי, בלעדיו פוש לא יעבוד.

ההתראה נשלחת לכל המכשירים הרשומים של המשתמש. לחיצה עליה פותחת את התשובה עצמה.

## ניהול משתמשים (מנהל בלבד)
בלשונית משתמשים אפשר: להוסיף משתמש, לשנות קוד ידנית, לאפס לקוד אקראי חדש, ולחסום או לשחרר.
משתמש חסום אינו יכול להיכנס.

## הזרימה
1. מדביקים הודעה של לקוחה. קודם התאמה מדויקת, בחינם.
2. אם אין, המנוע החושב שואל השלמות בכפתורים או מציע ניסוח.
3. שולחים לאישור. המנהל מקבל התראה.
4. אישור כותב את התשובה לגיליון כ"מאושר", והשולחת מקבלת התראה.
5. מאותו רגע התשובה נמצאת בהתאמה מדויקת, בחינם.

## מבנה הקוד
- `lib/config.js` — הגדרות (מזהה גיליון, שמות לשוניות, מודל).
- `lib/sheets.js` — קריאה וכתיבה לגיליון.
- `lib/users.js` — משתמשים, אימות והרשאות.
- `lib/engine.js` — התאמה מדויקת בלי AI.
- `lib/ai.js` — המנוע החושב.
- `lib/wrap.js` — פתיחה, שם וחתימה.
- `api/` — נתיבי השרת.
