# MyPrime-CS · מערכת חיפוש חיה - מדריך העלאה

האפליקציה קוראת את התשובות ישירות מגיליון Google Sheets החי שלך, דרך הקישור.
כל שינוי בגיליון מופיע מיד, בלי לשלוח קובץ חדש.

הקישור לגיליון שלך כבר מוטמע בקוד, אז נשארו רק שני דברים.

## שלב 1 - לשתף את הגיליון לצפייה (פעם אחת)
1. בגיליון, לוחצים על "שתף" (Share) הכחול למעלה.
2. תחת "גישה כללית", בוחרים "כל מי שיש לו את הקישור" (Anyone with the link).
3. מוודאים שהתפקיד לידו הוא "צופה" (Viewer), לא עורך.
4. שומרים.

בלי זה, האפליקציה לא תוכל לקרוא מהגיליון.

## שלב 2 - להעלות ל-Vercel (כרגיל)
מחברים את התיקייה לגיט ולוורסל בדיוק כמו בכל אפליקציה שבנית. מקבלים קישור קבוע, ושולחים אותו לטלי ולאפי.

## אם החלפת גיליון בעתיד
פותחים את `lib/config.js` ומעדכנים שם את מזהה הגיליון ואת שם הלשונית. זה המקום היחיד.

## טוב לדעת
- מוצגות רק שורות שהסטטוס שלהן "מאושר" ושהסוג שלהן "מענה". טיוטות והודעות יזומות לא מופיעות בחיפוש.
- אם עמודת "נוסח סופי / תיקון" מלאה, מוצג הנוסח ממנה במקום התשובה המקורית.
- סינון סוג הלקוחה עובד לפי עמודת "סוג לקוחה". תשובה בלי סימון מוצגת בכל הסינונים.
- הקריאה מהגיליון עוברת דרך שירות חינמי (opensheet) שממיר גיליון משותף לנתונים. מתאים לכלי פנימי. אם תרצה בעתיד בלי שירות חיצוני, אפשר להוסיף קורא משלנו.
